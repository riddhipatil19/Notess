## ADD COLUMN

The `ALTER TABLE` statement is used to **modify the structure** of an existing table.  
To **add a new column** to an existing table, we use the `ADD COLUMN` clause.
### Syntax

```sql
ALTER TABLE table_name
ADD COLUMN column_name datatype [constraints];
```
### Example

```sql
ALTER TABLE employees
ADD COLUMN age INT;
```

---
## DROP COLUMN

The `DROP COLUMN` command is used with `ALTER TABLE` to remove an existing column from a table.
### Syntax

```sql
ALTER TABLE table_name 
DROP COLUMN column_name;
```
### Example

```sql
-- Remove the 'age' column from 'students' table
ALTER TABLE students 
DROP COLUMN age;
```

## RENAME 

The `RENAME` functionality allows you to change the **name of a table** or a **column**.

## 1. Rename Table
### Syntax

```sql
ALTER TABLE old_table_name
RENAME TO new_table_name;
```
### Example

```sql
ALTER TABLE students 
RENAME TO learners;
```

## 2. Rename Column
### Syntax

```sql
ALTER TABLE table_name
RENAME COLUMN old_column_name TO new_column_name;
```
### Example

```sql
ALTER TABLE books
RENAME COLUMN pages TO num_of_pages;
```

## MODIFY COLUMN

The `MODIFY COLUMN` command in SQL is used to **change the datatype, size, or constraints** of an existing column in a table.  
It does not rename the column (for renaming use `CHANGE` or `RENAME COLUMN`).
### Syntax

```sql
ALTER TABLE table_name
MODIFY column_name new_datatype [constraints];
```
### Example

```sql
ALTER TABLE employees
MODIFY title VARCHAR(300);
```

---
## CHANGE

The `CHANGE` clause in MySQL is used to **rename an existing column** and optionally modify its datatype or constraints.
### Syntax

```sql
ALTER TABLE table_name
CHANGE old_column_name new_column_name new_datatype [constraints];
```
### Example

```sql
ALTER TABLE employees
CHANGE title book_title VARCHAR(500);
--- Rename and modify both
```
