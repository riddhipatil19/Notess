DATA QUERY/RETRIEVAL LANGUAGE (DQL or DRL) 
DQL (Data Query Language) is a subset of SQL focused on retrieving data from databases. The SELECT statement is the foundation of DQL and allows us to extract specific columns from a table. 
- **SELECT:** 
	- The SELECT statement is used to select data from a database. 	```
	- If you want to select all the fields available in the table, use the following
	- syntax: 
	```sql
	SELECT * FROM table_name; 
	```
	Ex: 
	```sql
	SELECT CustomerName, City FROM Customers;
	```

---

- **CONCAT:** 
	- The `CONCAT()` function is used to join two or more strings into one.
	- Syntax: 
	```sql
	SELECT CONCAT(author_fname," ",author_lname) 
	AS author_name 
	FROM books;
	```
	Ex: 
	- CONCAT_WS seperates the words with whatever value you give first. 
```sql
	SELECT CONCAT_WS(" ",author_fname,author_lname) 
	AS author_name 
	FROM books;
```
- COALESCE replace all the null values of first_name with ""
```sql
SELECT CONCAT(COALESCE(first_name, ''), ' ', COALESCE(last_name, '')) AS full_name 
FROM employees;
```

---


- **SUBSTRING():** 
	- The `SUBSTRING()` function in SQL is used to **extract a part of a string** (i.e., a substring) from a given string.
	```sql
	SUBSTRING(string, start_position, length)
	```
	Ex:  In the give example, 1 is the start index and 10 is the length:
	```sql
	SELECT SUBSTRING(title, 1, 10) AS 'short title' FROM books;
	```

---

- **REPLACE():** 
	- **REPLACE()** is a string function in SQL that replaces all occurrences of a specified substring with another substring.
	```sql
	SELECT REPLACE(title," ","-") From books;
	```

---

- **REVERSE():** 
	- ****REVERSE()** is a string function in SQL that returns the reverse of the given string.
	```sql
	SELECT REVERSE(author_fname) FROM books;
	```

---

- **CHAR_LENGTH():** 
	- **CHAR_LENGTH()** is a string function in SQL that returns the number of characters in a given string.
	```sql
	SELECT CHAR_LENGTH(author_fname) FROM books;
	```

---

- **UPPER():** 
	- **UPPER()** is a string function in SQL that converts all letters in a string to uppercase.
	```sql
	SELECT UPPER(author_fname) FROM books;
	```

---


- **LOWER():** 
	- **LOWER()** is a string function in SQL that converts all letters in a string to lowercase.
	```sql
	SELECT LOWER(author_fname) FROM books;
	```

---

- **DISTINCT:** 
	- Removes duplicate rows from query results. 
	- Syntax: 
	```sql
	SELECT DISTINCT author_lname FROM books;
```

---

- **ORDER BY** 
	- The ORDER BY clause allows you to sort the result set of a query based on one or more columns. 
	- Syntax: 
	```sql
	SELECT column1, column2 FROM table_name ORDER BY column1 [ASC|DESC]; 
	```

---

- **LIMIT** 
	- **LIMIT** is a clause in SQL that restricts the number of rows returned by a `SELECT` query. 
	```sql
		SELECT column1, column2 FROM table_name ORDER BY ASC LIMIT 5; 
	```

---

- **LIKE:** 
	- The LIKE operator is used in a WHERE clause to search for a specified pattern in a column. 
	- There are two wildcards often used in conjunction with the LIKE operator: 
		- The percent sign (%) represents zero, one, or multiple characters
		- The underscore sign ( _ ) represents one, single character 
	```sql
		SELECT * FROM employees 
		WHERE first_name LIKE '_J%'; 

		SELECT * FROM employees 
		WHERE first_name LIKE '%\%%'; 
```
