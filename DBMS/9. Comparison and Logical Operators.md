## Comparison Operators

Comparison operators are used to compare two values in SQL.  
They return a boolean result (`TRUE`, `FALSE`, or `NULL`).

| Operator | Description | Example | Result |
|----------|-------------|---------|--------|
| `=`      | Equal to    | `salary = 5000` | TRUE if salary is exactly 5000 |
| `<>` or `!=` | Not equal to | `salary <> 5000` | TRUE if salary is not 5000 |
| `>`      | Greater than | `salary > 5000` | TRUE if salary is more than 5000 |
| `<`      | Less than    | `salary < 5000` | TRUE if salary is less than 5000 |
| `>=`     | Greater than or equal to | `salary >= 5000` | TRUE if salary is 5000 or more |
| `<=`     | Less than or equal to | `salary <= 5000` | TRUE if salary is 5000 or less |
| `BETWEEN` | Between a range | `salary BETWEEN 3000 AND 5000` | TRUE if salary is between 3000 and 5000 |
| `IN`     | Matches any value in a list | `dept IN ('HR', 'IT')` | TRUE if dept is HR or IT |
| `LIKE`   | Pattern matching | `name LIKE 'A%'` | TRUE if name starts with A |
| `IS NULL`| Checks if value is NULL | `manager_id IS NULL` | TRUE if manager_id is NULL |

---

## Logical Operators

Logical operators are used to combine multiple conditions in SQL queries.

| Operator | Description                                | Example                           | Result                        |
| -------- | ------------------------------------------ | --------------------------------- | ----------------------------- |
| `AND`    | TRUE if **all** conditions are true        | `salary > 3000 AND dept = 'IT'`   | TRUE if both conditions match |
| `OR`     | TRUE if **at least one** condition is true | `dept = 'HR' OR dept = 'Finance'` | TRUE if dept is HR or Finance |
| `NOT`    | Reverses the result (negates)              | `NOT dept = 'HR'`                 | TRUE if dept is not HR        |

---

## Example Usage

```sql
-- Employees with salary > 5000 in IT department
SELECT *
FROM employees
WHERE salary > 5000 AND dept = 'IT';

-- Employees not in HR or Finance
SELECT *
FROM employees
WHERE dept NOT IN ('HR', 'Finance');

-- Employees whose name starts with 'A'
SELECT *
FROM employees
WHERE name LIKE 'A%';
```

## CASE
The `CASE` statement in SQL is used for conditional logic.  
It allows you to return values based on conditions, similar to `IF-ELSE`.

---

## Syntax

### Simple CASE
```sql
CASE expression
    WHEN value1 THEN result1
    WHEN value2 THEN result2
    ...
    ELSE resultN
END
```

#### Simple Case
```sql
SELECT title,
    CASE category
        WHEN 'Fiction' THEN 'Story'
        WHEN 'Science' THEN 'Knowledge'
        ELSE 'Other'
    END AS CategoryType
FROM books;
```

#### Searched Case
```sql
SELECT title, pages,
    CASE
        WHEN pages > 500 THEN 'Long Book'
        WHEN pages BETWEEN 200 AND 500 THEN 'Medium Book'
        ELSE 'Short Book'
    END AS BookLength
FROM books;
```
